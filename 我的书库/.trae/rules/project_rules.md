# 知识库项目 · 开发与使用规则

> 本文件随「我的书库」文件夹走：在 TRAE 中打开「我的书库」文件夹作为工作区时自动加载生效。
> 工作区内本目录即书库根（含 书籍\、检索脚本\），规则内路径均相对本目录书写。

## 编码军规（第一条，违反即返工）
- 所有脚本与文档文件读写一律 `encoding='utf-8'`，禁止 GBK/ANSI。
- **唯一例外：`.bat` 批处理文件必须保存为 GBK（代码页 936）+ CRLF 换行，首行 `@echo off` 后紧跟 `chcp 936 >nul`**。cmd.exe 默认按 GBK 解析批处理，UTF-8 编码或 LF 换行会导致中文行错位、命令被吞（如 `%~dp0` 变 `dp0`）。bat 内禁止使用 GBK 无法编码的字符（如 `✅`，用 `[OK]` 代替）。
- 所有路径拼接一律基于项目根目录（含 `路径配置.json` 的目录），用 `pathlib` 相对推算，**禁止绝对路径字面量**。
- 唯一入口配置文件：项目根 `路径配置.json`（含目录路径与 `阈值` 节）。所有脚本经 `common.load_config()` / `common.get_path()` 读取。

## 执行规则（TRAE 里让 AI 干活时必须遵守）
1. 完成任何文件改动后，先跑对应脚本的 `--自检` 再交付。
2. 检索知识库必须调用 `检索脚本\search_keyword.py`：
   - `--fetch "词"` 组合动作（#63，**默认优先**）：查询+定位+原文一趟给齐（每命中块输出 块ID+行号区间+指纹+原文逐字全文，默认前 5 块）；
   - `--query "词"` 关键词检索（自动简繁归一 + 术语表扩展；#4 M2 起支持逗号分隔多词，如 `--query "排龙,水口"` 合并榜单；输出带「⚠️ 弱命中」时表示仅碎片匹配、应谨慎引用或换词重查）；
   - `--locate "块ID"` 现场定位块（**不读**建库时缓存的行号，现场扫描原文.md）；
   - `--verify "块ID" "预期指纹"` 指纹比对，±50 行内自动纠偏。
   - 禁止直接用人工行号/硬编码行号；块 ID 用锚点映射里的**指纹**（该块首正文行检索副本前 12 字）定位与纠偏。
3. 引用块内容必须带块 ID（如 `【0001·0007】`），否则视为无出处、不采信。
4. 查询词未命中时，允许用同义词表/近义词二次查询，但必须明示"未直接命中"。
5. 知识库全部内容需经管线入库，禁止把外部文本直接塞进 `书籍\`。

## 检索协议（在 TRAE 对话内查询知识库时必须遵守）
1. 三条检索路径（按序判断，不两难）：
   - 提问含明确术语/专名 → 先查 `书目总索引.md` 选书（含「分类」列，用户点名类别时按类筛书并明示所选书目）→ 该书 `目录骨架.md` 选章 → `章节摘要\` 标签/锚点表直达块 ID；
   - 模糊关键词 → `search_keyword.py --query "词"`；**简繁归一与术语表扩词是检索前置动作**（脚本已内置完成），禁止跳过脚本直接逐字比对原文；
   - 语义联想/首查未命中 → 拆词、换同义词再次 `--query`，回退 n-gram 全文扫，仍无则明示"未直接命中"。
2. **标注回环铁律**：标签索引未命中 ≠ 原文没有，必须回退 n-gram 全文扫描后方可下结论。
3. 块 ID 是身份证不是顺序号，数字跳跃属正常（书籍更新后老块退休、新块尾部领号）；阅读顺序以目录骨架/原文物理顺序为准；`--locate` 查无此块或报已退休时，按退休口径如实应答，不得静默改指其他块。
4. **效率口径（#63，省的是往返轮次）**：优先 `--fetch "词"` 一趟拿全（候选块的 块ID+行号+指纹+原文逐字全文一次返回，默认前 5 块），只需榜单概览才用 `--query`；多个查询词必须合并为一次 `--query/--fetch "词1,词2"`（各词独立检索、榜单合并），禁止拆成多个串行调用（**逗号合并仅限 `--query`/`--fetch`**；`--locate`/`--verify` 一次只收一个块 ID，多个块同轮并发多条单块命令）；无依赖的工具调用必须同一轮并发发出，禁止逐层串行等待；`--verify` 只核验最终将引用的块（≤5 块）；读原文按行号区间只读命中块，禁止整读原文.md。
5. 输出固定格式：📖定位（书名/块ID/印刷页码）→ 📜原文（引用块原文，每段引用前标《书名》+印刷页码、段末以【块ID】收口——书名页码供用户阅读定位、块ID作防伪复核锚；跨多本书逐段标全，禁止只写块ID）→ 🧠讲解 → 📝总结；**单次最多引用 5 块，超出须声明"仅取前 5 块"**。页码语义：印刷页码；未拟合/降级块以 `PDF.页序` 括注标明（如 `PDF.156`）；非分页书为顺序号。
6. **生效宣告**：每次会话首次按本协议作答时，回答第一行固定输出 `🔎 已按知识库检索协议检索`，同会话后续回答不重复；**未走检索流程的回答一律不得带此标记**（用户以此判断 AI 是否真查了书：无标记/无块 ID 的回答＝凭印象作答，可打回要求按协议重查）。

## 管线顺序（不可跳卡）
入库：`extract.py` → `quality_check.py`（红灯即停）→ `clean_split.py` → `build_index.py` → 移入已入库。
标注：`verify_needles.py`（密文自检）→ `annotate_pack.py --生成` → 外部 AI 回填 → `annotate_pack.py --导回` → 术语确认写入术语表。
评测：`eval_gen.py --判分 <回答文件>`（回答文件每行 `| 题号 | 回答 |`）。

## 红线
- 原文层逐字转录、块不可改：已出生的块内容零改动；书籍更新只允许经 update_book 整块增/删/换（老块退休+新块领号），禁止改写既有块内容；密文验证等处理用副本，验证前后比对文件哈希自证。
- 退出码约定：0=成功/绿灯，1=失败/红灯，2=部分成功。脚本异常不弹栈，写 `报告\`（项目根）对应报告。
